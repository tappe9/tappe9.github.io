# tappe9.github.io

アプリのプライバシーポリシーを公開するための静的サイトです。

## 構成

- `index.html`: 公開中のプライバシーポリシー一覧
- `<AppName>/privacy-policy/index.html`: 各アプリのプライバシーポリシー
- `assets/site.css`: 共通スタイル

新しいアプリを追加する場合は、`<AppName>/privacy-policy/index.html` を追加し、トップページの一覧へリンクを追加します。

## 公開 URL

- ArrowNavi Compass: https://tappe9.github.io/ArrowNavi/privacy-policy/
