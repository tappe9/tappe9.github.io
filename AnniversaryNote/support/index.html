AnniversaryNote

サポート

最終更新日: 2026年6月2日

AnniversaryNote は、誕生日や記念日を記録し、今日・もうすぐの予定や月ごとのカレンダーで確認するためのアプリです。

使い方

  • 初回起動時に、最初の記念日を登録できます。
  • ホーム画面では、今日の記念日、現在の経過年数、もうすぐの記念日を確認できます。
  • 一覧画面では、記念日の検索、並べ替え、種類での絞り込みができます。
  • カレンダー画面では、月ごとの記念日を確認できます。
  • オプション画面では、テーマ、ホームの表示範囲、通知タイミングを変更できます。

よくある確認事項

通知が届かない

オプション画面でリマインダーが有効になっていること、iPhone の通知許可が有効になっていることを確認してください。通知を許可していない場合は、iOS の設定アプリから通知を許可できます。

2月29日の記念日が通常年でどう扱われるか

うるう年ではない年は、2月29日の記念日を2月28日として扱います。

登録した内容を別の端末で確認できない

現在のバージョンでは、記念日データは端末内に保存されます。別端末との自動同期やバックアップ機能は提供していません。

広告が表示される

無料アプリとして継続提供するため、画面内に広告が表示される場合があります。

お問い合わせ

不具合やサポートが必要な場合は、公開サポート用 GitHub Issues からご連絡ください。個人情報、Apple ID、誕生日や記念日の詳細、通知内容などは投稿しないでください。
